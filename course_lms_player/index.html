The Mental Model Shift

In React 19 and Next.js App Router, components default to React Server Components (RSC). Unlike traditional Server-Side Rendering (SSR) where the entire page generates HTML and hydrates all JavaScript into the DOM, RSC code never bundles to client machines.

Execution Pipeline Topology RSC Wire Format vs Hydration Tree
